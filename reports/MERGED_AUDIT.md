# TripWise Shanghai — объединённая база (19 ноября 2026)

**Область изменений:** исключительно база POI и встроенные JSON-данные HTML. Алгоритм маршрутизации не изменён. Новая версия — архив `tripwise_shanghai_realistic_data_v1.zip`, предыдущая — пользовательский `TripWise_Shanghai_2000_READY_preview_and_data_2026-11-19(2).zip`.

## Итог

- **2000 POI**: 500 исходных записей из предыдущей версии сохранены с их ID, названиями и координатами; 1500 синтетических записей отобраны из новой версии.
- 472 записей из исходного OSM-снимка сохранены, но **не были независимо повторно геопроверены**.
- Синтетические координаты учитывают модель близости к метро и районную плотность; **это не подтверждённые реальные адреса, здания, тротуары или входы**.
- Во всех 1500 синтетических POI `name_ru` теперь содержит русское обозначение типа объекта + исходное латинское вымышленное имя (не проверенный перевод китайского названия).
- Все `opening.closed_weekdays` используют допустимые значения 1–7; `0` не обнаружен. Расписание по-прежнему синтетическое и не подтверждено официальными часами работы.

### Важные ограничения

1. Для независимого пересчёта метро-метрик использованы **344 координаты станций из приложенного предыдущего архива**, а не упомянутые в отдельном отчёте **418 станций новой модели**: полного списка 418 в обоих ZIP нет. Метрики не строго сопоставимы с прежними оценками 418 станций.
2. **64 POI с соседями ближе 20 м** включают исходную геометрию 500 сохранённых мест; их нельзя автоматически разнести, не нарушив условие не менять координаты реальных записей. Минимум равен 0 м из-за совпадающих геометрий в исходной базе.
3. Полный OSM-граф дорог/тротуаров, здания, вода, входы метро и пешеходные OSRM-маршруты не проверялись. Даже модельные координаты с высоким рейтингом близости к метро могут быть на недоступных территориях.
4. Сценарии маршрутизации 16/16 из предыдущей версии **не переносим как доказательство качества объединённой**: на новых POI эти тесты не запускались. JS-алгоритм оставлен как был; в приложенном HTML подменена только база JSON без изменений остального HTML.
5. Карта покрытия и PNG — визуализации **модельных координат**, а не подтверждённых POI.
