TRIPWISE — изменение синтетических данных Шанхая (19.11.2026)

Это ZIP ТОЛЬКО с изменёнными файлами. База: 2000 POI, 1500 перемещено из
аномального юго-западного кластера, музеи: 11 -> 90 (79 новых синтетических сценариев).

УСТАНОВКА
1. Распаковать архив в КОРЕНЬ своей локальной папки TripWise, сохраняя
   подпапки data/, artifacts/, scripts/, tests/, reports/, docs/.
2. Подтвердить замену файлов в data/ и artifacts/.
3. Открыть artifacts/tripwise-shanghai-coverage.html — карта всех точек.
   Открыть artifacts/tripwise-shanghai.html — алгоритм маршрутов.

ВАЖНО ДЛЯ ТОЧНОГО СОХРАНЕНИЯ ТВОЕГО ТЕКУЩЕГО АЛГОРИТМА
Ветку могли обновить после того, как был собран HTML. Чтобы не перезаписать
более свежий JS текущего проекта, можно перед распаковкой сохранить текущий
artifacts/tripwise-shanghai.html, распаковать ZIP, восстановить свою копию
этого HTML, затем выполнить в корне проекта:
    python scripts/refresh_shanghai_html.py
Скрипт перезапишет ТОЛЬКО встроенные данные, оставив алгоритм неизменным.

В новой базе координаты синтетические: расположены рядом с уже имеющимися
POI, но нахождение строго вне дороги/внутри здания НЕ подтверждалось.
Не применять для реальной навигации.
