# Расширение московского каталога TripWise, v7

В каталоге **19 510 POI**. Сохранены все 1 826 исходных записей и добавлены **17 684** именованных объектов OpenStreetMap. Извлечено 19 196 кандидатов в границах Москвы. Исключено 1 511 дублей и 1 запись без текстового названия. Все итоговые количества и категории ниже пересчитаны после чтения сохранённого JSON.

«Добавлено» показывает только новые POI, а чистое изменение учитывает и пересмотр исходных записей. Один объект может входить в несколько категорий. Проверено 501 исходных записей музейной тематики. Категории или основная категория изменились у 42 исходных POI, из них 40 получили хотя бы одну новую категорию. Исторические музеи получают `history, museums` с основной `history`. Музеи современного искусства получают `museums`. Для решений использованы названия, тематика OSM и сохранённая классификация v5. Поштучная проверка музейных специализаций по официальным сайтам не проводилась.

## География и качество

- Зеленоградский административный округ — 222 новых POI.
- Новомосковский административный округ — 682 новых POI.
- Троицкий административный округ — 249 новых POI.

- Граница города — административное отношение OSM №102269, версия 427. Для каждого нового POI проверено попадание в полигон с учётом исключённых территорий. В исходной базе 1 точек за границей этого полигона. Их идентификаторы перечислены в `EXPANSION_STATS.json`. Эти записи сохранены с исходными координатами.
- Распределение новых точек по способу получения координат приведено в статистике. Использованы узлы OSM, центроиды, внутренние точки и середины линий. Для площадей используется центроид внутри геометрии и города либо внутренняя точка пересечения. Для линейного объекта используется середина линии, когда она внутри Москвы. Координаты входов, расписание и текущий статус работы новых объектов требуют отдельной проверки.
- Дедупликация использует типизированный OSM ID, идентификатор Wikidata для некоммерческих объектов и близость совпадающих имён. Для ближайших одноимённых коммерческих объектов учтены адреса и тип геометрии. Похожие имена и спорные соседние филиалы оставлены для проверки с протоколом в `duplicates_review.csv`. В нём 527 пар с новыми записями и 9 пар между исходными. Автоматическое сопоставление может пропустить переименования и случаи с заметным расхождением координат.
- Проверены уникальность TripWise ID, отсутствие пересечения типизированных OSM ID новых и исходных объектов, сохранность всех полей исходных записей кроме музейной классификации и согласованность трёх экспортов по ID, координатам и категориям. Число повторяющихся типизированных OSM ID в самой исходной базе — 0.

Семь исходных тестов московского каталога также прошли. По неполной или некорректной исходной геометрии см. счётчики в EXPANSION_STATS.json.

## Источники

- База v5 из снимка `snapshot/tripwise-current` (`020124bb`). Исходные сведения об источниках сохранены в каждой записи. [Исходный каталог](https://github.com/weiffii/TripWise/blob/020124bb0f842bf2659aae3bb1ef04171c395a8f/pois_real_master_v5.json)
- Одна полная региональная выгрузка Geofabrik, состояние OSM на `2026-11-19T21:22:20Z`. Данные новых POI — © OpenStreetMap contributors, ODbL 1.0. [Geofabrik](https://download.geofabrik.de/russia/central-fed-district.html), [атрибуция и лицензия](https://www.openstreetmap.org/copyright)
- Городская граница и контрольные границы трёх округов получены через основной OSM API. Выгрузка BBBike проверена как запасной вариант. Её охват не включает Зеленоград и юг Новой Москвы, записи из неё не добавлялись. [Граница Москвы](https://www.openstreetmap.org/relation/102269)

Ветка для результата — `feature/moscow-poi-expansion` в изолированной локальной копии. Путь новых файлов — `data/expansions/moscow-poi-expansion-v7/`.
