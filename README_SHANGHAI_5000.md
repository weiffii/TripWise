# TripWise Shanghai 5000 — готовый data-only выпуск

Дата: **2026-11-19**. Это **готовая расширенная база**, а не генератор, который нужно запускать пользователю.

## Что получено

- `data/demo/shanghai/pois.json`: **5000 готовых POI**, первые 2000 полностью совпадают с выбранным архивом `TripWise_Shanghai_2000_MERGED_DATA_ONLY_2026-11-19.zip`.
- `artifacts/tripwise-shanghai.html`: прежний рабочий планировщик с новым каталогом; алгоритмы не менялись.
- `artifacts/tripwise-shanghai-coverage.html`: прежняя карта покрытия с 5000 POI и категориями; без новой логики интерфейса.
- `artifacts/TripWise_Shanghai_5000_POI_COVERAGE.png`: отдельно готовая обзорная картинка + увеличенный центр; без OSM-подложки дорог.
- `reports/SHANGHAI_5000_AUDIT.md`, `reports/shanghai_5000_qa.json`, `reports/shanghai_26_route_scenarios.json`: результаты проверки.
- `reports/PROBLEMS_FOR_CODEX.md`: обнаруженные ограничения, **алгоритмы не изменялись**.

## Генерация, конфигурация, повторное использование

`config/shanghai.json`: границы сценария, валюта CNY, timezone Asia/Shanghai, центр, 8 категорий, соотношения категорий/радиусов, прокси районов/активностей, источник метро и seed.

`config/shanghai_name_lexicon.json`: местные лексемы и категории на `zh/en/ru`; при переносе в другой город нужно подставить **другую местную лексику и характеристики**.

`data/sources/shanghai_metro_centres_418.csv`: 418 сохранённых в архивном генераторе округлённых станционных координат; фактическая актуальность на 2026-11-19 отдельно не подтверждена.

`scripts/expand_city_pois.py`: воспроизводимый генератор добавлений, **не трогает существующие записи**. Он возвращает тот же результат с одинаковым seed и исходным файлом. Если ему передать уже созданную базу из 5000, он не создаёт места повторно.

Для независимого повтора **в будущем**, имея исходный выбранный архив с 2000 POI:

```bash
python scripts/expand_city_pois.py --config config/shanghai.json --base /path/to/selected-2000/data/demo/shanghai/pois.json
python scripts/audit_shanghai_5000.py --base /path/to/selected-2000/data/demo/shanghai/pois.json
node tests/run_shanghai_5000_scenarios.cjs
```

*Эти команды не нужно выполнять для получения результата: результат уже находится в ZIP.* Для аудита и карты необходимы `numpy`, `scipy`, `matplotlib` из `requirements-data.txt`. Для воспроизводимости генератора достаточно Python 3 и стандартной библиотеки. Для тестов маршрутизатора — Node.js.

Для другого города поменяйте конфиг и центр, локальные названия, подходящую модель транспортных узлов/районных центров, пространственные границы, валюту/временную зону и рыночные цены/время работы. Если метро нет, `metro_source` можно сделать `null`; тогда координаты размещаются относительно районных центров. **Это моделирование, не копирование географии Шанхая**. Полноценная проверка пригодности здания/дороги требует локального OSM-графа и границ, которых нет в этом выпуске.

## Источники и ограничения

Новые 3000 POI — вымышленные. Ни один новый POI не был проверен по геометрии реального здания, дороги, входа, водного полигона. Метрики близости к метро и кафе рассчитаны по прямой, не по уличной сети. Оригинальные OSM POI в числе первых 2000 сохранены с прежними ссылками. Источник исторических OSM записей: © OpenStreetMap contributors, ODbL 1.0 — https://www.openstreetmap.org/copyright. Открытый экстракт Shanghai: https://download.geofabrik.de/asia/china/shanghai.html (скачать не удалось в этой среде).
