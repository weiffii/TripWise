Названия и координаты добавленных объектов взяты из существующих наборов OSM и Shanghai Library, однако записи не проверялись вручную и могут отражать устаревшие или неточные объекты. Для названий на других языках использована транслитерация, если точный перевод неизвестен; это не равно проверенному переводу. Остальные параметры демонстрационные.

Архив содержит готовый файл `data/demo/shanghai/pois.json`; никакие скрипты запускать не требуется. Старый HTML не заменяется.
