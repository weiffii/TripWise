# Локальный запуск OSRM для Москвы

FastAPI, SQLite и Route Assistant запускаются по инструкции из [README](../../README.md). Docker Compose поднимает два необязательных сервиса OSRM для дорожных маршрутов. При выключенных сервисах TripWise обозначает переходы по прямой как ориентировочные.

## Запуск с готовыми графами

Для запуска нужны уже подготовленные MLD-графы и локальный образ OSRM той версии, которой собраны графы. В корне каталога графов должны быть подкаталоги `foot` и `car` со всеми файлами `map.osrm*`. Используйте пешеходный и автомобильный профили соответственно.

По умолчанию Compose ищет графы в `runtime/moscow-osrm`. Для другого расположения задайте путь к общему каталогу через `MOSCOW_OSRM_GRAPH_DIR`. Запуск из корня TripWise в PowerShell:

```powershell
docker compose -f compose.moscow-osrm.yaml config -q
docker compose -f compose.moscow-osrm.yaml up -d --pull never
.\START_TRIPWISE.bat
```

Параметр `--pull never` использует локальный образ. По умолчанию это OSRM 5.27.1, как в [скрипте подготовки](../../scripts/prepare_moscow_osrm.ps1). Если графы собраны другой версией, перед запуском задайте `MOSCOW_OSRM_IMAGE` с её локальным именем и тегом. Compose монтирует графы в режиме чтения и публикует сервисы на `127.0.0.1` отдельно для каждого профиля.

Если доступны только файлы одного профиля, укажите `foot` или `car` последним аргументом команды `up`.

Если 5001 или 5002 уже занят ранее запущенным OSRM, используйте этот сервер. Для перехода на Compose сначала остановите экземпляр, занимающий тот же порт.

## Проверка и запуск приложения

```powershell
curl.exe -fsS "http://127.0.0.1:5001/route/v1/driving/37.6200,55.7520;37.6240,55.7539?overview=full&geometries=geojson"
curl.exe -fsS "http://127.0.0.1:5002/route/v1/driving/37.6200,55.7520;37.6240,55.7539?overview=full&geometries=geojson"
$env:MOSCOW_OSRM_FOOT = 'http://127.0.0.1:5001/route/v1/driving'
$env:MOSCOW_OSRM_CAR = 'http://127.0.0.1:5002/route/v1/driving'
.venv/Scripts/python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
```

Адрес `driving` одинаковый у двух сервисов. Пеший или автомобильный профиль определяется графом, который загружен в конкретный сервис. Проверка должна вернуть `code: Ok` и дорожную геометрию из графа выбранного профиля. При запуске через Windows-файл `START_TRIPWISE.bat` локальные сервисы определяются автоматически. Если приложение уже работало до запуска OSRM, перезапустите FastAPI, чтобы он увидел адреса.

Остановка сервисов:

```powershell
docker compose -f compose.moscow-osrm.yaml down
```

Если готовых графов нет, но имеется локальный файл `.osm.pbf` с покрытием Москвы, соберите графы отдельно через [скрипт подготовки](../../scripts/prepare_moscow_osrm.ps1). Команды Compose выше используют готовые графы.
