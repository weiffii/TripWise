## Установка и проверка

Распаковать ZIP в корень существующего репозитория с сохранением путей и заменой файлов. Работа маршрутизатора не требует повторной сборки HTML. Для синхронизации после любых последующих изменений JSON можно выполнить `python scripts/refresh_shanghai_html.py`.

Проверки (из корня репозитория):

```powershell
python -m unittest discover -s tests -p test_shanghai_synthetic_rebalance.py -v
node tests/test_shanghai_data_final.cjs
```

Тесты Node используют **существующий** `ai_ds/web_demo/shanghai-engine.js`. Дополнительные runtime-библиотеки не добавлены. Данные не нужно выдавать за фактически существующие объекты или адреса; у реальных OSM-идентичностей изменилась только демонстрационная география.

## Ограничения для следующего этапа Codex

Точное пересечение с дорогами, береговой линией, водой, зданиями и фактической доступностью входов **не проверено**. Зона тестирования и банк выведены эвристически из исходных POI. В пеших сценариях с питомцем `no_gaps` иногда остаётся `failed` несмотря на достаточность питания и допустимых POI — это отдельная проблема построения расписания, а не причина менять исходную синтетическую базу без анализа.
