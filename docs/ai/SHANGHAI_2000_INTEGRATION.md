# Shanghai 2000 — интеграция

- В `artifacts/tripwise-shanghai.html` находится автономный интерактивный демо-планировщик с каталогом 2000 объектов.
- В `artifacts/tripwise-shanghai-coverage.html` находится самостоятельная карта покрытия города с фильтрами по категориям.
- База `data/demo/shanghai/pois.json` содержит все 2000 тестовых объектов с тремя языковыми вариантами названия и координатами.
- В планировщике убрано ошибочное сообщение «100 объектов»; добавлены переключение языков, поиск и отображение локализованных названий.
- Сборщик `scripts/build_shanghai_demo.py` должен запускаться на исходниках проекта из ветки `feature/ai-ds` после применения изменённой базы. Сборка может отличаться от вложенного HTML, если исходный шаблон изменится.
- Действующий в архиве исходный HTML предыдущей сборки был обновлён локально; полное побайтовое соответствие HTML текущей версии GitHub не подтверждено.
- Внешние подложки карт и маршрутизаторы требуют сети; DEMO-BUS и свойства объектов синтетические.
