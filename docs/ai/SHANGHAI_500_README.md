# Shanghai: построение каталога из 500 реальных объектов OSM

**В этом ZIP нет выдуманной «готовой базы из 500 реальных мест».** Прямой доступ к OSM/Overpass в среде подготовки архива отсутствовал. ZIP содержит изменённый сборщик и загрузчик, которые создают полноценный каталог после успешной загрузки реальных именованных объектов. До запуска прежняя база остаётся 100-объектной.

## Как запустить

1. Распаковать ZIP поверх **актуальной** ветки `feature/ai-ds` с сохранением путей.
2. При рабочем интернете запустить `BUILD_SHANGHAI_500.bat` в корне проекта. Если `python` не найден, заменить в bat на доступный Python 3.11+.
3. Скрипт обращается к Overpass API с запросами на именованные туристические объекты Шанхая, валидирует 500 уникальных названий/ID, сохраняет `data/demo/shanghai/pois.json`, затем пересобирает **существующий** `artifacts/tripwise-shanghai.html`. Новые HTML не создаются.
4. При ошибке сети / нехватке результатов файл исходного каталога не переписывается. Можно повторить позже.

## Реальные и демонстрационные данные

- Только названия и координаты OSM (для ways/relations центр геометрии, **не вход**), плюс 28 ранее помеченных проверенными мест. Каждый новый объект имеет URL `https://www.openstreetmap.org/{type}/{id}`.
- Длительности, цены, отзывы, часы, доступность с животными, сезонность и степень загруженности — **демонстрационные гипотезы**, их необходимо заменить реальными значениями перед использованием в поездке.
- Выборка включает музеи, историю, парки, гастрономию, развлечения, торговлю и другие категории. Отбор пространственно разнообразный, не рейтинг популярности.
- Источник: © OpenStreetMap contributors, лицензия ODbL: https://www.openstreetmap.org/copyright. Требуется атрибуция при распространении.

## Ограничения

Доступность публичных серверов Overpass не гарантируется. Крупный запрос может быть отклонён или ограничен. Никаких платных ключей не требуется. Существующие код маршрутизации, HTML-шаблон и интерфейс не меняются. Время движения по OSM/OSRM и реальные входы в здания отдельно не проверялись.

Для воспроизведения на заранее загруженном ответе OSM: `python scripts/build_shanghai_demo.py --overpass-json путь_к_overpass.json`.
