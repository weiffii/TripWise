# Встроенный чат TripWise: результат 20 ноября 2026

## Что работает

В существующий `artifacts/tripwise-shanghai.html` добавлен чат: свободный ввод/Enter, очередь сообщений, уточнения и продолжение диалога, читаемый предварительный просмотр мест, порядка, времени, стоимости, дороги и предупреждений. До подтверждения маршрут и карта не меняются. «Применить изменения» повторно проверяет предложение и обновляет расписание, карту и показатели; «Оставить прежний маршрут» отклоняет предложение. Новое построение по анкете сбрасывает старый контекст интерфейса.

Разрешены добавление по названию/категории/близости, удаление необязательного POI или перекуса, замена достопримечательности/ресторана, более дешёвый ресторан, перенос между днями/изменение порядка, время существующего завтрака/обеда/ужина, темп дня, ограниченное изменение числа посещений, оптимизация дороги/ожиданий/пеших переходов, изменение транспорта и окончания дня. Связанные операции выполняются одной атомарной попыткой. Обязательные места и полноценное питание не удаляются автоматически.

## Архитектура и файлы

- `ai_ds/route_assistant.py`: совместимые точки расширения существующего Store/version/fingerprint/preview/confirm, исходный механизм сохранён.
- `ai_ds/openrouter.py`: существующий бесплатный интерпретатор с отдельным prompt и ограниченным контекстом текущего диалога. Числовые цены проверяются явно. Только `openrouter/free`, без платного fallback; ключ только в окружении сервера.
- `ai_ds/shanghai_assistant.py`: адаптер служебной схемы 0.2 к native `shanghai-demo-v1`, поиск ограниченного контекста, диалог, сессии, CSRF, request-id/idempotency, проверка снимков и понятные ошибки.
- `ai_ds/web_demo/shanghai-engine.js`: `scheduleSequences`, `validateEditedTrip`, `editTrip`. При редактировании полный `planTrip()` не вызывается. Используется фиксированный набор остановок и тот же JS-движок/данные/транспорт/правила 150/180 минут. Незатронутые дни сохраняются полностью.
- `ai_ds/web_demo/shanghai-assistant-bridge.cjs`: ограниченный JSON stdin/stdout мост без выполнения произвольного кода и без путей из запроса.
- `scripts/serve_shanghai_demo.py`: существующий локальный сервер расширен API, карта и tile proxy сохранены.
- `ai_ds/web_demo/shanghai-chat.js`, `examples/shanghai-demo/template.html`, `scripts/build_shanghai_demo.py`: интерфейс, безопасный обмен, встраивание в прежний HTML. Таблица исходных рекомендаций сохраняется после compact-ответа API.

Подробности: `shanghai-chat-contract.md`, `shanghai-fixed-editing.md`. База 5000 POI не менялась: SHA-256 `72184b2b6a221be96535529fb70e78fb3146b1707c4411ec1b4bcd34d240380d`. Ни ключа, ни новых POI, ни новых внешних зависимостей в HTML нет.

## Запуск

В текущем сеансе запущен **настоящий live API**, не mock:

http://127.0.0.1:8771/tripwise-shanghai.html

Для повторного запуска двойной щелчок по `START_SHANGHAI_MAP.bat`. Требуются Python и Node.js в PATH серверного процесса, а также серверная переменная `OPENROUTER_API_KEY`; в текущем окружении ключ настроен. Из обычного Windows-запуска Node также должен быть доступен. Альтернативная команда: `python scripts/serve_shanghai_demo.py --port 8771`. Сервер открывает браузер; при занятом порте выбирает свободный. Старое окно сервера нужно перезапустить, чтобы у него появились новые API-маршруты.

Открытие самого HTML файлом сохраняет обычный маршрутизатор, но для чата нужен сервер: браузер не получает API-ключ и не обращается с ним к провайдеру напрямую.

Затем запрос обеда в 14:00 отклонён как невыполнимый при сохранённом наборе остановок; исходная версия не изменена. Третий запрос завершился недоступностью интерпретатора/провайдера, успешная правка не имитировалась. Подробности: `reports/assistant-2026-11-20/live-provider.json`.

Пример проверенного mock-диалога через настоящий UI/API: «Замени музей на парк» → «В какой день?» → «Во второй» → preview → отклонение → «Нет, лучше другой парк во втором дне» → новый preview → подтверждение. Это интеграционный тест, не доказательство неизменной доступности бесплатного LLM.

## Честные ограничения

- Бесплатный OpenRouter может быть недоступен, ограничен квотой или неправильно интерпретировать запрос; неограниченное понимание естественного языка не гарантируется. При ошибке маршрут остаётся прежним.
- Если полноценного приёма пищи в исходном частичном плане нет, его восстановление через `set_meal_break` пока не реализовано (`MEAL_NOT_IN_ROUTE`). Добавить отдельную гастрономическую остановку можно.
- Удаление/замена обязательного места этим контрактом запрещены; явное пожелание не обходит защиту. Можно переносить его при выполнимости.
- Для невозможного запроса выводится причина и предложение изменить время/день/число посещений. Автоматический поиск математически ближайшей допустимой альтернативы для любого сочетания пожеланий не реализован.
- Ограниченный поиск кандидатов и перестановок не является глобальным оптимумом. Длительности/цены/часы и значительная часть POI синтетические, транспортные оценки сохраняют прежние ограничения.
- Сессии и маршруты находятся в памяти локального процесса и не переживают его перезапуск. Это локальная интеграция, не публичная многопользовательская production-инфраструктура. Москва в чат не подключалась.
- Полный Python discover с историческими проверками старого каталога в этой итерации не объявляется зелёным: запускались перечисленные релевантные 60 тестов. `TASKS.md` не отмечен завершённым без подтверждения владельца.

При остатке около 5% пятичасового лимита пользователь уведомлён; дальнейшее расширение остановлено ради завершения проверок и отчёта.
