## Что значат координаты

Построены синтетические «условные площадки» внутри треугольников исходных POI одного берега. Детерминированная hex-сетка и географические квоты предотвращают полное совпадение точек. **Это не гарантирует**, что полученная координата не совпала с дорогой, водой, забором или недоступной территорией. Каждая из 1500 новых POI имеет:

- `provenance.coordinates=synthetic_urban_parcel_unverified`;
- `synthetic_location.building_footprint_verified=false`;
- `synthetic_location.road_clearance_verified=false`;
- `synthetic_location.water_clearance_verified=false`;
- `coordinate_review.status=synthetic_plausible_unverified`.

Ссылки `source_url` и `original_coordinate_source_url` относятся только к исходной записи каталога, **не** к новой точке.

## Согласованность свойств

- Музеи: 79 вымышленных названий с разными темами; часы преимущественно 09:00–18:30; закрытие по воскресеньям; небольшая часть — условные открытые экспозиции, допускающие животных.
- Природа: 110 новых условных скверов, садов и прогулочных зон; доступность и сезонность моделируются отдельно.
- Развлечения: 130 условных интерактивных площадок; для тестирования есть ограничения по группам и по понедельникам.
- Смотровые: 70 условных точек панорамы; наличие реальной обзорной высоты не подтверждено.
- Кафе: разные утренние/вечерние часы, чеки и допуск питомцев; бренды трактуются как названия исходного каталога, не подтверждение существования филиала в новой точке.
- Значения `rating`, `review_count`, `price_cny`, `avg_check_cny`, `opening`, `season_months`, `pet_friendly`, `family_friendly`, `senior_friendly` у новых POI демонстрационные.

## Повторная проверка после передачи Codex

```powershell
python -m unittest discover -s tests -p test_shanghai_synthetic_rebalance.py -v
node tests/test_shanghai_data_final.cjs
```

Скрипт `scripts/refresh_shanghai_html.py` существует в репозитории и не модифицировался. Если меняется JSON, запустить скрипт, чтобы синхронизировать два существующих HTML. Не запускать старый генератор 5-метровых смещений и не изменять вручную встроенные литералы.

**Сохранённое ограничение:** в первых 500 записях были две пары совпадающих координат; они не созданы этим изменением и оставлены без переноса реальных/исходных объектов. Одинаковые названия сетевых кафе в разных местах не считаются дублями автоматически.
