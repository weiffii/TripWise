# Shanghai500: интерфейс, имена и локальная карта

Дата: 19 ноября 2026. Статус: готово с ограничениями для общей приёмки. Внешняя сеть и браузер этим исполнителем не запускались; реальную проверку в обычном браузере выполняет основной агент.

## Сохранённая основа

Сохранены пользовательские 500 POI, состав группы, валюты, детали транспорта и двухэтапный алгоритм. Алгоритмические файлы и исходная база этим исполнителем не менялись. Устаревшие подписи «100 объектов / 72 вымышленных» заменены счётчиками из текущего набора и его меток происхождения. Метки не выдаются за новую независимую проверку всех мест.

## Обычный браузер и карта

Причина первоначальной неисправности на компьютере пользователя не объявляется доказанной по чтению кода. Для исключения прямой зависимости браузерных изображений от file://, Referer и блокировки внешнего домена добавлен узкий same-origin proxy в существующий локальный HTTP-сервер.

GET /tiles/{z}/{x}/{y}.png допускает только целые z0..19 и координаты x/y в диапазоне0..2^z−1. Сервер обращается исключительно к фиксированному tile.openstreetmap.org, использует постоянный идентифицирующий User-Agent и передаёт фактический Referer локального приложения. Это не proxy для произвольных URL. Репозиторий и другие файлы не выдаются. /health публикует только имя сервиса, версию tile-proxy-v1 и поддержку proxy.

Кешируются только тайлы, которые потребовались при обычном просмотре. Cache-Control, Expires, Age, ETag и Last-Modified учитываются; устаревшие записи запрашиваются условно. Если сервер не сообщил срок свежести, используется семь дней; no-store не записывается на диск, no-cache не считается свежим. PNG проверяется по типу и сигнатуре, размер ограничен1MiB. Кеш записывается атомарно с уникальными временными файлами и проверкой хеша тела. Фоновая предварительная загрузка, выгрузка города и платные сервисы не добавлялись. Кеш artifacts/osm-tile-cache/ исключён из Git.

При открытии через loopback HTTP изображения идут по /tiles на том же origin. При старом обработчике без /health карта пишет «Локальный сервер устарел», не бесконечную загрузку. Нужно заново запустить START_SHANGHAI_MAP.bat: существующий механизм выберет свободный порт и откроет его. Старый процесс не убивается. При file:// показана заметная инструкция запуска. Нейтральный фон, точки и управление картой сохраняются при недоступности подложки.

Новые зависимости не добавлялись. Сам upstream может быть недоступен сети компьютера; proxy не создаёт изображения из воздуха. Это остаётся явной диагностируемой ошибкой.

## Названия и средний чек

Добавлен переключатель языка названий Русский / English / 中文. Один resolver читает p.names[ru/en/zh], а при отсутствии перевода возвращает исходное p.name и пометку «оригинальное название». Исходный объект не переписывается. Переключатель обновляет расписание, кандидатов, каталог, обязательные места, легенду, маркеры и popup; выбор обязательных мест сохраняется. Поиск каталога и обязательных мест учитывает все доступные языковые значения.

Это поддержка трёх языков, а не утверждение, что перевод всех500имён уже имеется. Полнота определяется данными и отдельно показывается в интерфейсе. Названия станций в полученных транспортных инструкциях остаются из своего источника; они не выдаются за проверенный русский перевод.

Для ресторанов отображаются avg_check_cny и price_segment, либо совместимый fallback на price_cny. Средний чек показан вCNY на одного взрослого и явно отмечен синтетическим; стоимость события на всю группу выводится отдельно. Никакой второй суммы поверх цены группы UI не добавляет. Внедрение основано на подтверждённом другим агентом ценовом gate, API здесь не вызываются.

В смешанном режиме подпись поясняет сравнение пешком/ОТ/такси по плановому времени среди допустимых по группе и бюджету вариантов. Это не обещание глобальной оптимальности или live-пробок. Списки «Не поместились в этот день» об опциональных местах скрыты, сообщения еды/обязательных точек и ошибок не скрываются.
