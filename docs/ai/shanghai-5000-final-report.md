# TripWise Shanghai: итоговая проверка 5000 POI

19 ноября 2026. Готова локальная демонстрация маршрутизатора `bounded-joint-insertion-v5` на существующем каталоге. Сборка успешна; HTML проверен в Chrome через HTTP и как отдельный файл. Полную готовность командного приложения, реальные туристические сведения и глобальную оптимальность этот отчёт не утверждает.

## Что исправлено

- `ai_ds/web_demo/shanghai-engine.js`: вместо последовательного жадного заполнения — совместный ограниченный поиск по дням, beam для обязательных мест, вставки и проверяемые 2-opt/переносы. Главные и дополнительные интересы участвуют в отборе; сохранены резервы категорий и географии. Обязательные объекты защищены от удаления обычной оптимизацией, включая обязательные рестораны.
- Длительность берётся из данных с умеренной поправкой на темп: большой музей больше не обрезается до 95–105 минут. Темп не создаёт жёсткой квоты, которая исключает выполнимые обязательные посещения.
- Питание подбирается после достопримечательностей по дополнительному времени пути `A→ресторан→B − A→B`, цене группы и допустимым часам. Учитываются условные завтрак/обед/ужин, перенос завтрака после раннего музея и завтрак перед обязательным обедом. Нехватка денег на еду не удаляет выполнимое обязательное посещение.
- Предварительный пространственный поиск, ограниченный резерв и дешёвая оценка вставок сокращают число дорогих пересчётов. Полностью проверяются лучшие 12 ходов за раунд с расширением до 36 при необходимости. Приём каждого хода проверяет реальные для модели времена, бюджет, часы и группу. Поиск ограничен 6000 проверок расписания; исчерпание поиска не объявляется доказанной невозможностью.
- `ai_ds/web_demo/shanghai-transit.js`: ограниченный кэш ближайших станций. Поиск пути, точная минута отправления, часы автобуса, тарифы и инструкции сохранены. Полной матрицы 5000×5000 нет.
- `examples/shanghai-demo/template.html`: расчёт в WebWorker, отмена устаревшего запроса, ошибки/таймаут; поиск по всем 5000 местам с порционным выводом каталога. Сохранены анкета, языки, дни, карта и пересчёт с полученными дорожными временами.
- `scripts/build_shanghai_demo.py`: актуальные 5000 POI/2000 заведений, проверки данных и безопасного встраивания; удалена скрытая строковая подмена алгоритма при сборке. Обновлён именно `artifacts/tripwise-shanghai.html`.

Исходный каталог не менялся. SHA-256 до/после: `72184b2b6a221be96535529fb70e78fb3146b1707c4411ec1b4bcd34d240380d`. Итоговый engine: `086603f0b162f829eaf053625c8835af81d1d8986623dc4c0a08f974278e39c3`. Встроенные engine/transport совпадают с исходниками, встроенные POI — с исходным JSON.

В Chrome по HTTP финальный прогон дал 0,429 / 1,048 / 1,013 с на 1/3/5 дней для настроек интерфейса. При открытии файлом — 0,369 / 0,923 / 1,205 с. Это отдельный профиль и один прогон, его нельзя подставлять вместо одинакового сравнительного стенда. Интервальный счётчик продолжал работать во время расчёта, подтверждая отсутствие блокировки основного потока. Сетевые карты, локальный прокси тайлов и внешние маршрутизаторы в этих браузерных тестах блокировались: проверена работа интерфейса при недоступной сети, а не наличие живой подложки/геометрии.

Полный набор тестов **не зелёный**. Шесть Python failures в `test_shanghai_synthetic_rebalance.py` требуют прежние 2000 мест, 79 специальных музеев, 389 старых сценариев, старые геометрические признаки/покрытие едой и другой HTML. Этих данных в пользовательском каталоге больше нет. Три JS-файла — `test_shanghai_500.cjs`, `test_shanghai_engine.cjs`, `test_shanghai_data_final.cjs` — также требуют 500 мест/старый synthetic fixture; дополнительная диагностика выявила ожидания старого rollback-счётчика, обязательного `source_url` даже у вымышленных объектов и прежних формулировок предупреждений. Они не скрывались и не отключались. Отдельная проверка оставшихся применимых утверждений не обнаружила нового нарушения ограничений. Актуальный контракт каталога проверяет новый `test_shanghai_5000_data.cjs`.

## Как посмотреть

Готовый файл: **`artifacts/tripwise-shanghai.html`**. Для обычного запуска с сетевой картой откройте **`START_SHANGHAI_MAP.bat` двойным щелчком** в корне проекта. Устанавливать зависимости и вводить команды не требуется при наличии текущего Python. Для просмотра маршрута без сервера можно открыть сам HTML.

В текущем сеансе также запущена демонстрация: http://127.0.0.1:8767/tripwise-shanghai.html . Эта ссылка локальная и работает, пока процесс сервера запущен.

Для наглядного сравнения выберите «Культура» и «Природа», затем 1/3/5 дней, главные и дополнительные интересы, обязательные места и транспорт. Нажмите построение. Смотрите состав посещений, питание, бюджет, вкладки дней и карту. При нехватке бюджета или закрытом обязательном месте результат показывает ограничение; частичный результат не считается полным.

## Оставшиеся ограничения и следующий шаг

- В каталоге 4500 явно вымышленных POI. Цены, средние чеки, рейтинги, длительности, часы и сезонность демонстрационные; геометрия синтетических мест не проверена по зданиям, воде и входам. Новые данные в этой работе не добавлялись.
- Топология метро из опубликованного набора не равна актуальному расписанию. Входы/выходы, доступность, ожидание и тарифы оценочные; 30 автобусных маршрутов вымышленные и помечены DEMO-BUS. Неподтверждённые переходы остаются оценками, не выдаются за реальные улицы. OSM зависит от сети/доступности сервиса; дорожная матрица частичная, пробок нет.
- Поиск ограничен: может пропустить допустимое улучшение, набор или ресторан. Точные графовые тесты не доказывают полноту на произвольных больших входах. Начальная/конечная точка каждого дня — POI; отель, возврат в отель и междневной переезд не моделируются.
- Python Route Assistant сохранён и тестируется, но его schema 0.2 не подключена напрямую к JS HTML. Текстовое редактирование и сохранение через backend партнёра остаются интеграционной работой; совместимый план описан в `docs/ai/shanghai-5000-assistant-integration.md`.
- Следующий шаг — перенести исторические тесты на независимые малые fixtures и актуальные контракты, затем согласовать backend-адаптер и замену тестовых полей достоверными источниками. Это не требует менять текущий пользовательский каталог ради прохождения старых тестов.

`TASKS.md` не отмечался завершённым без подтверждения владельца. Предложение к обновлению: зафиксировать проверенный локальный Shanghai 5000 demo; backend, реальные данные и AI-интеграцию оставить отдельными незавершёнными задачами.
