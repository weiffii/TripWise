## Подтверждённые результаты

- Четыре разрешённые валюты проходят сохранение/загрузку без изменения Decimal-суммы; неизвестные валюты отклоняются.
- Состав компании сохраняется и переживает перезапуск тестового сервера.
- `null`, отсутствующие ключи в явно переданном составе, лишние ключи, bool, строки, дроби, отрицательные значения, нулевая сумма, несовпадение общего количества и превышение лимита отклоняются без порчи сохранённой анкеты.
- Отсутствующее целиком поле старого клиента получает состав из взрослых. Старый raw JSON читается в новом формате без изменения исходных JSON, revision и updated_at в SQLite, включая повторный GET.
- Не вводятся неутверждённые возрастные границы, требования обязательного взрослого, скидки или автоматическое изменение темпа.
- Все шесть регрессионных проверок старой формы при смене аккаунта прошли: неверный/отсутствующий контекст отклонён, одинаковый revision не даёт перезаписать чужую анкету, правильный контекст не отменяет обычный конфликт версии.
- Вход, выход, независимые сеансы, ограничения попыток, Origin, защита внутренних файлов и отсутствие раскрытия пароля сохранились.

Подтверждённых backend-ошибок в проверенной области не обнаружено.

## Ограничения и передача

Статус серверного расширения: **готово к интеграции с frontend с указанными ограничениями**. Это не готовность полного MVP: реальные POI, построение маршрута, карта, Routing API и AI-редактирование в этой проверке отсутствуют. Новые возрастные группы и валюты пока только параметры анкеты, а не доказательство их учёта интеллектуальным модулем.

После окончания frontend требуется отдельно проверить сохранение и восстановление состава/валюты в браузере, EUR100 на человека при составе2+1+1 → EUR400 на компанию, светлую/тёмную тему на трёх страницах, сохранение темы и мобильную ширину. Координатор выполняет браузерную часть; её результат следует фиксировать отдельно, не приписывая этой HTTP-проверке.

## Дополнение: статическая проверка готового frontend

После сигнала координатора прочитаны `frontend/theme.js`, `questionnaire.js`, `trips.js`, `styles.css`, `index.html` и оба шаблона `backend/pages/`. Проверка — чтение реализации, **не браузерный тест**. Python после предыдущего прогона не менялся, поэтому HTTP-набор повторно не запускался.

Подтверждено по коду:

- На всех трёх страницах `/theme.js` подключён в head до CSS, переключатель — `button type=button`. Тема задаётся через `data-theme`, обновляются aria-label/aria-pressed и подпись действия. При отсутствии выбора учитывается системная тема, её изменение отслеживается; изменения настройки другой вкладки обрабатываются. Ошибки доступа к localStorage перехватываются. В localStorage сохраняется только ключ оформления, не анкета и не данные аккаунта.
- Светлая и тёмная палитры определены CSS-переменными, задан `color-scheme`, видимый focus и режим reduced-motion. Есть адаптивные правила для узкой ширины. Реальная читаемость, наложения и отсутствие горизонтального скролла требуют просмотра браузером.
- Три числовых поля состава имеют min=0, max=100, step=1, required; общий итог не редактируется отдельно. Сумма вычисляется из трёх полей, проверяется диапазон1–100, собственные ограничения каждого числа проверяет native `form.checkValidity()`. Пустое количество даёт NaN и блокирует сохранение.
- Сумма бюджета остаётся строкой при отправке, сохраняются min=0/max=1e9/step=.01. Итог компании вычисляется для отображения и форматируется через Intl с выбранной валютой; в пределах разрешённого бюджета и100 путешественников округление до двух знаков соответствует отображаемой денежной точности. На сервере остаётся Decimal. Валютный список соответствует серверу. Подпись прямо объясняет отсутствие конвертации и возрастных скидок.
- При загрузке восстанавливаются состав, валюта, исходная сумма и способ расчёта. Legacy fallback трактует отсутствующий состав как всех взрослых и отсутствующую валюту как RUB. Сервер отдельно выполняет нормализацию старого JSON.
- Карточка анкеты использует выбранную валюту, итог компании и три категории; hardcodedRUB в расчёте новой анкеты отсутствует.
- Owner-context исходной формы, последовательное автосохранение, revision, обработка401/409/428 и предупреждение о несохранённых правках сохранены.
- Фотография подключена из локального asset, предусмотрен локальный SVG-фон. В footer есть ссылка на автора/источник/лицензию. По сети шрифты и фото при обычном открытии страницы не запрашиваются.

Подтверждённых блокирующих ошибок в ходе статического чтения не найдено. Проверка синтаксиса JavaScript исполнением, браузерный сценарий EUR100×4, светлая/тёмная тема, сохранение выбора и мобильная ширина переданы координатору и не считаются выполненными этим QA.
