# Сервер: направления, валюты и несколько обязательных мест

Дата: 21 ноября 2026. Исполнитель: отдельный backend_agent. Основание — прямое изменение требований пользователем; общий AI/DS-контракт и алгоритмы напарника не изменены.

## Сделано

- `backend/catalog.py`: публичный GET `/api/catalog`, совместимый alias `/api/travel-catalog`.
- `frontend/assets/catalog.json`: единый локальный справочник UI, который читает и валидирует сервер. 7 стран, 8 городов, 16 мест (по 2 в каждом): Москва, Санкт-Петербург, Париж, Рим, Стамбул, Токио, Пекин, Лондон. Это доступный расширяемый список, а не все города мира.
- 155 кодов валют: RUB, USD, EUR, CNY первыми, остальные по коду. Исходный официальный [SIX List One XML](https://www.six-group.com/dam/download/financial-information/data-center/iso-currrency/lists/list-one.xml), публикация XML `2026-09-17`, получен 21 ноября 2026. Дубликаты стран удалены; записи IsFund=true и без численного minor units исключены. Коды металлов, тестовый XXX и отсутствие валюты не предлагаются. Названия в исходнике английские, frontend может локализовать их Intl.DisplayNames. Курсов и конвертации нет.
- `backend/drafts.py`: новая версия `fullstack-draft-0.2` принимает местные ISO datetime без UTC-смещения и IANA timezone из выбранного города. Сервер проверяет соответствие country/city/timezone, порядок времени, неоднозначные и пропущенные часы перевода летнего времени. Такие часы отклоняются с ошибкой и предложением выбрать другое время; fold молча не выбирается.
- Legacy `fullstack-draft-0.1` с московским aware-временем читается и сохраняется по старым правилам. GET не переписывает БД/revision.
- required_poi_ids: уникальный массив, максимум 20, каждый ID относится к выбранному городу. Несколько мест принимаются; неизвестные, повторные и из другого города отвергаются.
- Сохранение по явному PUT; сервер самостоятельно ничего не сохраняет при GET или открытии формы. Удаление frontend-автосохранения выполняет отдельный frontend_agent.
- Owner-context, session owner, revision, Origin, транзакция и Decimal сохранены.

## Происхождение мест и границы

Каждая запись имеет открытый source_url Wikipedia; страницы всех 16 мест реально открыты через web при подготовке. Локальные ID вида `local:paris:eiffel-tower` — внутренние ID справочника UI, не выданные за OSM/Wikidata ID. Сохраняются имена и ссылки, без скопированных описаний, координат, цен или часов работы. Эти записи не представляются как полноценный POI-набор рекомендательной системы. Отображение списка и сохранение пожеланий не подтверждают генерацию маршрута или учёт обязательных мест алгоритмом.

## Проверки

Команда:

```sh
NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost .venv/bin/python -W error::ResourceWarning -m unittest discover -s tests/fullstack -p test_destinations.py -v
```

7/7 реальных HTTP-тестов прошли за 3.521 s на временной БД и собственном порту. Покрыты все направления, несколько POI, сохранение/GET, приоритет валют, неизвестные и чужие ID, country/city/timezone mismatch, DST gap/fold и отсутствие записи по GET. `py_compile` трёх Python-файлов и `git diff --check` прошли. Это проверки разработчика, независимая приёмка передана QA. Реальные runtime/аккаунты и пользовательский сервер не менялись.

## Передача QA

Старый `test_travel_party.test_unknown_currency_rejected` содержит GBP, который теперь законно поддерживается: адресно заменить этот ошибочный пример на ZZZ/XXX, сохранив остальные проверки и новый отдельный позитивный GBP roundtrip. Остальные legacy-направления 0.1 остаются только московскими — они не требуют ослабления тестов. Запустить общий HTTP-набор и проверить frontend-явное сохранение отдельно браузером.

Ограничение: бюджетная анкета по-прежнему принимает до двух знаков после запятой для всех валют как ранее согласованный параметр планирования. ISO minor_units приведены в справочнике для происхождения, но это не платёжная система и расчёт денежных переводов не реализован.

Для объяснения студентке: каталог — общий список допустимых вариантов, по которому и браузер показывает выбор, и сервер проверяет полученные значения.
