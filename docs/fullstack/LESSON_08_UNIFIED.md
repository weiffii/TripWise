# Занятие 8. Интерфейс и генератор в одной ветке

Дата: 22 ноября 2026. Документ объясняет согласованное объединение; результаты независимого QA учитываются отдельно.

## Что объединяется

Ветка `feature/fullstack-unified` создана от версии напарника `integration/fullstack-ai-ds` (`373aa1e`). В неё объединяется наша `feature/fullstack` (`209dc37`). Общий предок `bc1ef7d` уже содержит прежнюю работу сайта. Поэтому нужно сохранить последние изменения дизайна и нескольких поездок вместе с генератором, расписанием, картой и помощником, а не выбирать одну версию целиком.

`git switch -c` создал отдельную ветку, `git merge --no-commit --no-ff` подготовил объединение. Конфликт в семи файлах означает, что Git не может самостоятельно выбрать сочетание строк. Профильные агенты согласуют их по поведению. Исходные ветки и main сохраняются; итоговый коммит и публикацию подтверждает координатор после проверок.

## Как теперь идут данные

1. Анкета описывает пожелания для Москвы или Шанхая.
2. «Создать маршрут» отправляет параметры серверу.
3. Адаптер переводит имена полей и формат дат в контракт существующего движка, проверяя ограничения.
4. Результат живёт во временном серверном preview: это ещё не сохранённая поездка.
5. Экран результата показывает расписание/карту. «Редактировать» изменяет временную копию.
6. Только «Сохранить поездку» записывает показанный план в SQLite. При редактировании существующей поездки проверяется её версия.

Preview привязан к пользователю и текущему cookie-сеансу, доступен до60минут в одном серверном процессе. После перезапуска несохранённый результат может исчезнуть; сохранённый остаётся в базе. Прежние сохранённые анкеты и рассчитанные маршруты — разные типы карточек с разными ID.

## Ограничения и честные подписи

Москва: рубли. Шанхай: рубли/доллары/евро/юани с фиксированными учебными коэффициентами, не актуальными курсами. Доступны 1–5 дней, минимум час прогулки в каждый день, до30 человек каждого возрастного типа. Промежуточные дни09:00–21:00; первый и последний ограничены анкетой. Основных интересов1–8, транспорт и обязательные места передаются без молчаливого усечения.

По решению участницы от22ноября бюджет включает питание, посещения/развлечения и местный транспорт; дорога до города и проживание не входят. Реальные POI-ID берутся из каталога движка выбранного города. Оценки цен/времени, синтетические слои и недоступность внешнего помощника не выдаются за подтверждённые факты.

## Запуск на этом Mac

Нужны Python3.11+ и Node22+. На текущей установке обычный Node может отсутствовать в PATH; у Codex есть локальная копия:

```sh
PATH="/Applications/ChatGPT.app/Contents/Resources/cua_node/bin:$PATH" .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
```

PATH задаёт поиск программы Node только этой команде; остальная часть запускает Python-сервер. Это путь текущего Mac, а не универсальная установка для всех участников. На другом компьютере Node должен быть установлен отдельно. Новые внешние провайдеры этим срезом не подключаются.

## Проверки и практика

На момент записи: координатор сообщил о67 прошедших HTTP-проверках и20 тестах рекомендаций. Один прежний модуль discovery не импортировался из-за отсутствующего httpx2; весь discovery не объявляется зелёным. Девять preview-тестов исполнителя используют контролируемый генератор. Браузерный отчёт `/tmp/tripwise-unified-browser/result.json` имеет status=passed: настоящие движки обоих городов, отсутствие записи доSave, Saveбез дубля, две поездки, Edit/повторная генерация/Save с версией, отмена/подтверждение удаления, логотипнаглавную и мобильная тема375pxбез переполнения. Внешняя сеть заблокирована; работа живого LLM и онлайн-подложки этим не подтверждена.

Практика: построить маршрут, открыть «Мои поездки» до сохранения, убедиться в отсутствии новой карточки; затем нажать Save и открыть сохранённый результат. Отредактировать его, отменить изменения либо сохранить новую версию и сравнить исходную запись. Для проверки используйте учебный аккаунт.
