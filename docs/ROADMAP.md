# TripWise — дорожная карта до защиты

> Последняя редакция: 16 ноября 2026. Основа — согласованный единый план 3 ноября — 2 декабря. **Это план, не отчёт о выполнении.** Прошедшие контрольные точки требуют проверки фактического результата; если работа отстаёт, приоритет отдаётся обязательному MVP.

## 1. Главные даты и правила

| Дата | Контрольная точка | Условие готовности |
|---|---|---|
| 3–8 ноября | ТЗ, интервью, архитектура | 4 интервью суммарно, анкета/сценарии, макеты, контракт, репозиторий, начальный прототип |
| 9–15 ноября | Первый полный сценарий | Параметры → маршрут по дням → карта → сохранение; базовый пеший переход или внешняя навигация |
| **16–22 ноября** | AI-редактирование и навигация | Текстовая правка с проверкой, реальные пешие расстояния/время и отображение, работающие ограничения |
| **22 ноября** | Ворота MVP | Если сценарий нестабилен — не добавлять Premium и другие новые функции |
| **23–26 ноября** | Пользовательские тесты | 3–5 тестов прототипа (в плане 4: по 2 у каждого), воспроизводимая исправленная ошибка, доказательства Skill и MCP |
| **26 ноября** | Фиксация объёма | После этой даты новые функции не начинать |
| **27 ноября – 1 декабря** | Стабилизация и подготовка | Тесты, README, 5–6 слайдов, репетиция, работающий запуск |
| **1 декабря** | Внутренний дедлайн | Финальный проверенный сценарий, ссылки и материалы |
| **2 декабря** | Защита | Демонстрация Free и, только если готов, Premium-текстового гида |

## 2. Исходный недельный план и нагрузка

Плановая исходная нагрузка: **по 44 часа на каждого**: 8 + 12 + 12 + 6 + 6 часов. Это оценка из согласованного документа, **не фактически отработанное время**.

### Неделя 1: 3–8 ноября (8 ч / участник)

**AI/DS:** два интервью, признаки и форматы персонализации, первичная логика ранжирования и метрики, тест агентного подхода.

**Product/Fullstack:** два интервью, макеты анкеты/маршрута/редактирования, GitHub и окружение, каркас сайта, предварительные API-контракты и CI по возможности.

**Результат:** ТЗ, исследование, архитектура, начальное демо, согласованные структуры. Проверить реальное состояние по `TASKS.md`.

### Неделя 2: 9–15 ноября (12 ч / участник)

**AI/DS:** POI-набор с источниками (3 ч), ранжирование (3 ч), дни/пешеходные переходы (3 ч), подключение LLM через абстракцию (3 ч).

**Product/Fullstack:** анкета (3 ч), API/сохранение (3 ч), карта/расписание/внешняя навигация (3 ч), интеграция всего сценария (3 ч).

**Результат:** поездка формируется, отображается и сохраняется. Если не готово на 16 ноября — задачи переносятся **в начало текущей недели**, а не считаются выполненными.

### Неделя 3: 16–22 ноября (12 ч / участник)

**AI/DS:** AI-редактирование готового маршрута (4 ч); проверка времени, длительностей, обязательных точек, пешеходных переходов (3 ч); при стабильности основного сценария — проверенные факты и рассказы для 3–5 мест Premium (3 ч); тесты разных интересов/бюджетов (2 ч).

**Product/Fullstack:** UI текстового редактирования (4 ч); карта/расстояния/время и предупреждения (3 ч); при стабильности — Premium-карточки (3 ч), иначе исправление интеграции; ручное и интеграционное тестирование (2 ч).

**Результат до 22 ноября:** Free-сценарий с работающим редактированием и реальной пешей навигацией; AI не выдаёт вымышленные данные; основные ограничения проверяются.

### Неделя 4: 23–26 ноября (6 ч / участник)

**AI/DS:** два пользовательских теста без подсказок (2 ч), исправление алгоритмических проблем (2 ч), подтверждение реального SKILL.md и MCP (1 ч), проверка интеграции (1 ч).

**Product/Fullstack:** два пользовательских теста (2 ч), исправление интерфейса/API/сохранения (2 ч), журнал делегирования агентам (1 ч), регрессионная проверка (1 ч).

**Результат:** суммарно не менее 4 фактических пользовательских тестов по исходному плану (требование курса: 3–5), хотя бы одна исправленная проблема с повторной проверкой, журналы инструментов.

### Неделя 5: 27 ноября – 1 декабря (6 ч / участник)

**AI/DS:** 1–2 слайда про данные/алгоритмы/ограничения (2 ч), финальные тесты и объяснение логики (2 ч), совместная репетиция (2 ч).

**Product/Fullstack:** слайды про проблему/продукт/исследование/модель дохода (2 ч), README и проверка чистой установки (2 ч), репетиция и демо (2 ч).

**Результат:** рабочий репозиторий, проверенный запуск, материалы и ответы на вопросы. Внутренний дедлайн — 1 декабря.

Это **разбивка исходной недели на дни**, согласованную недельную программу не заменяет. Даты задач подлежат корректировке по фактическому состоянию репозитория.

Если работы 9–15 ноября действительно не завершены, **они предшествуют** задачам по AI-редактированию независимо от дат таблицы.

## 4. Приоритеты до защиты

1. Блокеры запуска и общие контракты.
2. POI → рекомендации → расписание → карта → сохранение.
3. **Полноценные пешие переходы** с источником расстояния и времени.
4. Route Assistant через реальный LLM-провайдер с проверкой и подтверждением.
5. Пользовательские тесты, исправления, реальные доказательства Skills/MCP.
6. **Premium-демо:** факты и короткий текстовый AI-гид для 3–5 мест + экран тарифа, только при запасе времени.
7. Всё остальное — после курсовой.

## 5. Что не должно считаться завершённым

- Визуально красивый макет без работающего backend.
- Заглушка LLM вместо реально проверенного вызова.
- Синтетические POI как доказательство наличия реальной базы.
- Прямое расстояние между координатами как реальный пеший путь.
- Значок Premium без проверенных исторических/культурных фактов.
- Макет оплаты как работающий платёжный функционал.
- Код агента без воспроизводимого запуска и тестов.

## 6. Ежедневная синхронизация с `TASKS.md`

Analyst Agent читает `PROJECT_OVERVIEW.md`, `FEATURES.md`, `ROADMAP.md` и `TASKS.md`; сверяет задачи с фактическими файлами, PR и тестами; отмечает неизвестное как «не подтверждено»; готовит задания по исполнителям. Изменения дедлайнов, объёма MVP и ответственных сначала согласуются двумя участниками.
