# Визуальные ресурсы

`moscow-sunset.jpg` — фотография «Sunset over Moscow City», Юрий Д.К., CC BY 4.0.
Источник: https://commons.wikimedia.org/wiki/File:Sunset_over_Moscow_City.jpg
Лицензия: https://creativecommons.org/licenses/by/4.0/
Файл получен координатором; в CSS применяется кадрирование background-size: cover и поверх фотографии наложен затемняющий градиент для читаемости. Ссылка на автора и лицензию размещена в footer всех трёх страниц.

`moscow-panorama.svg` — декоративная авторская иллюстрация городского силуэта, созданная Frontend Agent. Используется как локальный запасной фон. Это иллюстрация, а не карта или доказательство существования туристического маршрута.

Изображения обслуживаются локально сервером TripWise. Удалённые шрифты, UI-библиотеки и фото-API не подключены.

## Города на главной

- `paris-sunset.jpg`: «Paris sunset», Zinneke, CC BY-SA 3.0. Источник https://commons.wikimedia.org/wiki/File:Paris_sunset.JPG . Лицензия https://creativecommons.org/licenses/by-sa/3.0/ . JPEG сохранён без изменений; в CSS применяется кадрирование, цветовой фильтр и затемнение.
- `istanbul-panorama.jpg`: Hunanuk, CC0. Источник https://commons.wikimedia.org/wiki/File:Istanbulpanorama.jpg . JPEG сохранён без изменений; кадрирование и цветовой фильтр выполняет CSS.
- `pace-calm.svg`, `pace-mixed.svg`, `pace-active.svg`: авторские декоративные иллюстрации Frontend Agent для карточек отдыха. Не фотографии и не туристические данные.
- Анимация главной — плавная смена фотографий с приближением (CSS), а не видеозапись городов. Есть кнопка паузы и поддержка reduced-motion.

`travel-landscape.svg` — авторская нейтральная иллюстрация путешествия, созданная Frontend Agent; не изображает конкретный город. Для направлений без локального фото показывается она, а не фотография другого города.

`card-*.svg` — авторские декоративные иллюстрации Frontend Agent для разделов анкеты, интересов, транспорта и компании. Это стилизованные картинки, не фотографии достопримечательностей и не источник туристических данных.
